Verify a signed report

Paste a verified report — the JSON file issued by the Verifiable Log Checker operator ({"report": …, "signature": …}). Your browser recomputes the Ed25519 signature over the report's canonical JSON against the service's published public key. Nothing you paste leaves this page: the only request made is fetching the public key, and the same check runs offline with tools/verify_report.py (stdlib-only Python) against the key committed in the spec repository.

What a valid signature attests: this exact verdict, over a journal with this head hash and record count, was computed by the operator's checker at the stated time. A report anyone edited afterwards — a flipped verdict, a changed count — fails.
