# The deck

`VLC-1.pptx` — 15 slides, built by `build.js` (pptxgenjs), with speaker notes on
the slides that need them.

Rebuild after editing:

```sh
node build.js
```

Every number on it comes from a script in this repository or from a cited primary
source. The status slide (standards dates) goes stale faster than anything else —
re-check it before presenting.
