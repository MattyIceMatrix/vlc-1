Bridges between different MCP transport protocols: stdio, SSE, and streamable
HTTP.

options:
  -h, --help            show this help message and exit
  --stdio STDIO         Local command to run, e.g. "uvx mcp-server-git"
  --connect-sse CONNECT_SSE
                        Connect to remote SSE endpoint URL
  --connect-streamable-http CONNECT_STREAMABLE_HTTP
                        Connect to remote streamable HTTP endpoint URL
  --grpc GRPC           gRPC server target (host:port) to expose
  --connect-grpc CONNECT_GRPC
                        Remote gRPC endpoint to connect to
  --expose-sse          Expose via SSE protocol (endpoints: /sse and /message)
  --expose-streamable-http
                        Expose via streamable HTTP protocol (endpoint: /mcp)
  --grpc-tls            Enable TLS for gRPC connection
  --grpc-cert GRPC_CERT
                        Path to TLS certificate for gRPC
  --grpc-key GRPC_KEY   Path to TLS key for gRPC
  --grpc-metadata GRPC_METADATA
                        gRPC metadata (KEY=VALUE, repeatable)
  --port PORT           HTTP port to bind
  --host HOST           Host interface to bind (default: 127.0.0.1)
  --logLevel {debug,info,warning,error,critical}
                        Log level
  --cors [CORS ...]     CORS allowed origins (e.g., --cors
                        https://app.example.com)
  --oauth2Bearer OAUTH2BEARER
                        OAuth2 Bearer token for authentication
  --ssePath SSEPATH     SSE endpoint path (default: /sse)
  --messagePath MESSAGEPATH
                        Message endpoint path (default: /message)
  --keepAlive KEEPALIVE
                        Keep-alive interval in seconds (default: 30)
  --stdioCommand STDIOCOMMAND
                        Command to run when bridging SSE/streamableHttp to
                        stdio (optional with --sse or --streamableHttp)
  --enable-dynamic-env  Enable dynamic environment variable injection from
                        HTTP headers
  --header-to-env HEADER_TO_ENV
                        Map HTTP header to environment variable (format:
                        HEADER=ENV_VAR, can be used multiple times). Case-
                        insensitive duplicates are rejected (e.g.,
                        Authorization and authorization cannot both be
                        mapped).
  --stateless           Use stateless mode for streamable HTTP (default:
                        False)
  --jsonResponse        Return JSON responses instead of SSE streams for
                        streamable HTTP (default: False)
